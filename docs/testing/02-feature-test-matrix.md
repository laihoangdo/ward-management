# Feature-to-test matrix

See [actual results](../audit/05-execution-results.md). Existing IT references below mean coverage exists in source, not that the complete suite passed.

All behavior is inferred from source pending business confirmation. Existing tests refer to inventory paths. E2E automation below is limited to named smoke cases; remaining cases are planned, not skipped tests. P0/P1 priorities follow data/security risk, not screen prominence.
